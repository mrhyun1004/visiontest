# 패치 메모리 이상 탐지 대시보드

Streamlit Community Cloud에 배포하는 간단한 이미지 이상 탐지 앱입니다.

## GitHub에 올릴 파일

이 폴더 안의 파일을 저장소 최상위(root)에 올립니다.

- `app.py`
- `requirements.txt`
- `mp_patch_detector.npz`

## Streamlit에 게시

1. GitHub에서 새 저장소를 만들고 위 세 파일을 저장소 최상위에 업로드합니다.
2. Streamlit Community Cloud에서 GitHub 계정으로 로그인하고 **Create app**을 선택합니다.
3. 저장소, 브랜치(`main`), 앱 파일 경로(`app.py`)를 선택해 배포합니다.
4. 배포된 앱 주소를 열어 이미지를 업로드해 확인합니다.

모델은 `정상패치메모리_이상탐지입문_Test.ipynb`의 모델 저장 셀에서 생성한 파일입니다. 앱은 업로드 이미지의 크기를 모델 입력 규격에 맞춰 조정하고, 패치별 점수와 전체 이상 점수를 계산합니다.

## 참고

이 저장소에는 데이터셋을 올릴 필요가 없습니다. 히트맵은 패치 단위 점수의 시각화이고, 판정은 결함을 확정하는 진단 결과가 아닙니다.
